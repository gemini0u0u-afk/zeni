# zeni

JavaScript React app built with Vite and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

## Source layout

- `src/components`: reusable UI components
- `src/hooks`: shared React hooks
- `src/lib`: library setup and shared integrations
- `src/pages`: page-level views
- `src/utils`: general-purpose helpers

Use `@/` to import files from `src`.
